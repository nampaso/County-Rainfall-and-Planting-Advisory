# Rainfall Data Cleaning & Planting Advisory Analysis

## Project Summary
This project processes and cleans monthly rainfall data across five Kenyan counties (Nairobi, Nakuru, Kisumu, Mombasa, and Machakos) for a farmer-support NGO. Using NumPy array operations without explicit loops where possible, the analysis identifies annual rainfall totals, wettest months, dry-month frequencies, and optimal consecutive two-month planting windows to support automated SMS planting advisories.
